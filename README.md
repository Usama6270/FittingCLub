# Fitting Club - Premium Sports Goods Website

A professional, animated website for Fitting Club, a Sialkot-based sports goods manufacturer and exporter.

## Image Replacement Guide

Below is a list of all placeholder image files you need to replace with your real images. All images should be placed in the `/assets/images/` folder.

| Placeholder File | Used In | Recommended Size | Notes |
|------------------|---------|------------------|-------|
| `/assets/images/favicon.png` | Browser tab icon | 64x64px | FC monogram style |
| `/assets/images/logo.png` | Navbar & Footer (dark backgrounds) | 200x60px (transparent PNG) | White logo on transparent background |
| `/assets/images/logo-dark.png` | Navbar (scrolled/light backgrounds) | 200x60px (transparent PNG) | Dark/red logo |
| `/assets/images/hero-bg.jpg` | Homepage hero section | 1920x1080px | Full-bleed banner image or video |
| `/assets/images/banner-about.jpg` | About page header | 1920x600px | Banner image |
| `/assets/images/banner-products.jpg` | Products page header | 1920x600px | Banner image |
| `/assets/images/banner-contact.jpg` | Contact page header | 1920x600px | Banner image |
| `/assets/images/category-1.jpg` to `/assets/images/category-6.jpg` | Homepage category cards | 800x1000px (portrait) | 6 category images |
| `/assets/images/product-1.jpg` to `/assets/images/product-12.jpg` | Featured carousel & products grid | 800x800px (square) | Product photos (you can add more following the same pattern) |
| `/assets/images/gallery-1.jpg` to `/assets/images/gallery-8.jpg` | About page gallery | 1000x750px | Facility/manufacturing photos |
| `/assets/images/cert-1.png` to `/assets/images/cert-6.png` | Certifications marquee | 150x80px (transparent PNG) | Certification badges |
| `/assets/images/testimonial-avatar-1.jpg` to `/assets/images/testimonial-avatar-4.jpg` | Testimonials | 150x150px (square) | Client photos/logos |

## Setup Instructions

1. Open `assets/js/main.js` and replace `92XXXXXXXXXX` with your actual WhatsApp number
2. Replace all placeholder images in `/assets/images/` with your real images following the guide above
3. Open `index.html` in a browser to view the website

## Features

- Fully responsive design
- GSAP scroll animations
- WhatsApp integration
- Product filtering
- Testimonial slider
- Mobile menu with animations

- HTML5
- CSS3
- Vanilla JavaScript
